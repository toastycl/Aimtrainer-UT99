# IGPlus / latency — deferred idea and archived prototype

This is a historical developer snapshot, excluded from the normal build, menu and player ZIP. The active project is standalone UT99 training: install the mod/map and play. Players must not be asked to install Python, IGPlus or a helper for the current trainer.

The integration was set aside at the owner's request because its setup burden outweighed its training value. Preserve the concept for later only if it can be delivered with a simple UT installation flow and no external runtime requested from players.

This snapshot is not maintained as an active build target. Moving its files changes their original relative paths. To reproduce the working 0.4.0 experiment, use repository commit `46ac0d25609294b85af6f1e38ddbc82dff6ec6d9` in a separate checkout. Its documentation/validation is historical, not a claim about the current standalone package.

Potential future scope: actual IGPlus player/weapons, free 0–300 ms additional RTT, separate native ping display, and reproducible server profiles. No person is assigned to finish this idea.
