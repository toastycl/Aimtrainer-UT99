# Roadmap

## 0.1 — Local source alpha

- [x] Neutral UT99 naming and standalone training source
- [x] Shock primary with fixed-sequence flicks and controlled strafe
- [x] Three profile slots, native settings panel and console commands
- [x] Session exporter and automated metrics checks
- [x] Compile with UCC 469e (0 errors, 0 warnings)
- [ ] Complete in-game acceptance on Windows, macOS and Linux

## 0.2 — Reproducible arena and comparisons

Dedicated arena with fixed starts and clear lanes; calibrated size/distance settings; in-game history and repeated-round comparisons; client/render/input metadata; reproducible compiler checks with separately provided original game dependencies.

## 0.3 — CTF weapons

Sniper flicks, microadjustments, continuous Pulse/Minigun tracking, Shock combos, Rocket/Flak prediction and aiming while moving/jumping/dodging.

## 0.4 — Client inputs

Verify runtime backend and per-OS/client support. Separate live changes from restart-required changes. Resume comparisons across restarts and restore original settings. Treat DPI/polling rate as user-provided unless verifiable.

## Later

Online lab with server-confirmed hits; intended netcode/movement/anticheat compatibility; agree on a source license before describing the project as open source.
