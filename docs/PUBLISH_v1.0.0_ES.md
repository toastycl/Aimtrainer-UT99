# Publicar v1.0.0 en GitHub

**Publicado:** [v1.0.0](https://github.com/toastycl/Aimtrainer-UT99/releases/tag/v1.0.0). El ZIP adjunto coincide con el paquete verificado. Los pasos siguientes se conservan como referencia del proceso manual.

1. Abre Releases → Draft a new release en el repositorio.
2. En Choose a tag escribe `v1.0.0` y selecciona crear ese tag. Target: `main`.
3. Título: `UT99 Aimtrainer v1.0.0`.
4. Copia el contenido de `docs/RELEASE_v1.0.0.md` al cuerpo del release.
5. Adjunta `UTAT-1.0.0.zip`. El archivo `UTAT-1.0.0-SHA256SUMS.txt` es opcional; ambos están disponibles en downloads. No adjuntes una carpeta de instalación de UT ni tus ini/logs.
6. Mantén Pre-release desmarcado y Set as latest release activado si aparece.
7. Pulsa Publish release. Comprueba que el tag sea v1.0.0 y que aparezca el ZIP adjunto.

El ZIP ya incluye instrucciones en español. Los Source code archives que agrega GitHub automáticamente no son el instalador del mod.
