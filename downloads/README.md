# Test build 0.3.0

[Download compiled mod + map](UTAT-alpha-0.3.0.zip?raw=true). With UT closed, replace both System files and the Maps file. Preserve your personal ini files. See the [Spanish guide](../docs/QUICKSTART_ES.md).

Random safe spawns, one Start button retaining weapon selection, and results over the room until a fresh primary fire returns to selection. Infinite ammo and timed rounds remain enabled.

[Optional IGPlus developer experiment](UTAT-network-lab-0.3.0.zip?raw=true) is separate: Shock/Sniper automated client/server proof with controlled localhost delay. It requires the base room and separately installed official IGPlus 11 packages. See [network lab status and instructions](../docs/NETWORK_LAB.md). It is not yet a selectable training mode.

Only project mod/map content is distributed. No original game or IGPlus packages are included. Linux engine/client integration passed; manual hardware/visual and Windows/macOS acceptance remain pending. See [validation](../docs/VALIDATION.md) and [SHA256 checksums](SHA256SUMS).
