# Standalone version 1.0.0

[**Download mod + map**](https://github.com/toastycl/Aimtrainer-UT99/releases/download/v1.0.0/UTAT-1.0.0.zip) · [Guía de instalación](../docs/QUICKSTART_ES.md) · [Validation](../docs/VALIDATION.md) · [Checksums](UTAT-1.0.0-SHA256SUMS.txt) · [Release notes](../docs/RELEASE_v1.0.0.md)

Copy the compiled mod/int/map into UT99 469e and open UT normally. Players need no Python, IGPlus, launcher or helper. Adds random aerial/evasive targets, distance and collision-scaled size options, and persistent native last-ten-round history. All eleven classic weapons, infinite ammo, random safe spawns and timed/free practice remain.

Earlier packages remain historical. Version 1.0.0 is published on [GitHub Releases](https://github.com/toastycl/Aimtrainer-UT99/releases/tag/v1.0.0). The release includes the installable ZIP; the optional checksum remains available here. No production deployment is involved.
